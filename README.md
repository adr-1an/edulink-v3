# About EduLink
EduLink is a multi-tenant school management platform built to provide schools with a centralized system for managing students, staff, classes, and other day-to-day operations. The backend is written in Go and uses PostgreSQL for persistent storage.

# AI usage in this app
**I am primarily a backend developer**. While I do know Next.js and frontend development, it isn't my main focus. I used Codex to write a significant portion of the frontend code, and I'm being transparent about that rather than pretending otherwise.
Specifically, the landing page was written entirely by AI and is only intended as a placeholder. Once the app goes into production, I'll replace it with a proper landing page.

The backend is entirely my own work. I designed its architecture and wrote and reviewed all of its implementation myself. I did use AI as a development resource for guidance, ideas, research, and second opinions, but no AI-generated code was blindly copied into the backend.

The API documentation (api.md) is an exception and was generated with AI assistance.
